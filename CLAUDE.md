# Repository instructions for Claude Code

## Git authorship

- **Never add Claude as a co-author.** Do not append `Co-authored-by: Claude`,
  `https://claude.ai/code/...` links, `Generated with` lines, or any other
  Claude / Anthropic attribution to commit messages.
- Always commit with `--author="Ratnaditya-J <ratna.ditya@gmail.com>"` so the
  commit author is the repo owner, not the Anthropic default identity.
- Pull request bodies follow the same rule — no `https://claude.ai/code/...`
  trailer.
